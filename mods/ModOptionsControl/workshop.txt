description=Server admins decide which [b]Mod Options[/b] (Options > Mods) players may change - and set the values for everyone. Build 42. Works with every mod that uses the game's own Mod Options (PZAPI.ModOptions); no other mod needs to be changed.
description=
description=[h2]How it works[/h2]
description=[list]
description=[*] [b]Default: everything stays free.[/b] Nothing changes until an admin locks something.
description=[*] Admins (everyone who may change the sandbox) open the [b]admin window[/b]: Admin Panel > Mod Options Control, or Options > Mods > Mod Options Control > Open admin window.
description=[*] Every mod page and every option has a rule: [b]-[/b] (inherit), [b]Locked[/b] or [b]Free[/b]. Click the left column to change it. Lock a whole mod with one click on its page row, or single options.
description=[*] Set your own values in Options > Mods as usual, then press [b]My values for all locked[/b] (or [b]Use my value[/b] for one option) and [b]Save & send[/b]. Without a value a locked option uses the mod's default.
description=[*] Players get the values instantly. Locked options are [b]hidden[/b] (default) so the list only shows what a player may change - or greyed out and marked [Server]. Players can show hidden ones greyed out on the Mod Options Control page.
description=[*] Players' own values stay saved in ModOptions.ini and come back in other games.
description=[*] Rules are saved with the world on the server. Export / Import to Zomboid/Lua/ModOptionsControl_rules.txt to copy them to another server.
description=[/list]
description=
description=[h2]Sandbox (page Mod Options Control)[/h2]
description=[list]
description=[*] Enable Mod Options Control
description=[*] Default rule: Free (default) or Locked
description=[*] Hide locked options (default on)
description=[*] Admins keep their own options (default on)
description=[*] Key bindings can be locked (default off - keys stay the player's choice)
description=[*] Always locked / Always free: optional lists like [i]ModPageID;OtherMod.optionID[/i]
description=[/list]
description=
description=[h2]Good to know[/h2]
description=[list]
description=[*] When joining a server the game reloads the server's Lua mods, so every mod a player sees in Options > Mods in multiplayer is a server mod.
description=[*] Mods with their own settings systems (older "Mod Options" library, own files) cannot be controlled.
description=[*] Values are applied through the mod's own option entries and its apply function, exactly like pressing Apply in the options.
description=[*] Server and client both need the mod (normal server mod). No Java, no ZombieBuddy.
description=[/list]
